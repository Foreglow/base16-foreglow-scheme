# Foreglow Base16 Scheme

Base16 YAML scheme for the Foreglow twilight-inspired theme.

## Installation

### Base16 Builder

```bash
base16-builder foreground foreglow
```

### Using base16-manager

```bash
base16-manager install foreglow
base16-manager set foreglow
```

### Manual

Copy `foreglow.yaml` to your Base16 schemes directory:

```bash
cp foreglow.yaml ~/.base16/foreglow.yaml
```
